# PDF Tools — Android APK project

**App name:** PDF Tools  
**Publisher label:** Sushila Engineering Works  
**Android application ID:** `com.sushilaengineering.pdftools`

This repository is prepared for a simple GitHub Actions workflow: push these project files to GitHub, open **Actions**, run **Build PDF Tools APK**, then download the `PDF-Tools-APK` artifact. The workflow installs Android build tools, bundles the browser libraries locally, creates the Capacitor Android project, and builds an installable debug APK.

## Included utilities

- PDF Viewer
- Photo to PDF Maker
- Merge PDF
- Split PDF (extract selected pages/ranges into one PDF)
- Compress PDF (rasterizes pages; see limitations below)
- PDF to Word (`.docx`, text extraction)
- Word to PDF (`.docx` or `.txt`, simplified text layout)
- Scan to PDF (phone camera/file picker images)
- PDF Editor & Sign (basic text note and hand-drawn signature overlay)

PDF files are processed locally by the app. The app does not send files to a PDF conversion server.

## Upload to GitHub

1. Download and extract the ZIP.
2. Open your target GitHub repository.
3. Upload **the contents of this folder**, not an extra parent folder. The `.github/workflows/build.yml` file must end up at the repository path `.github/workflows/build.yml`.
4. Commit the files to the `main` branch (or `master`).
5. Open the repository's **Actions** tab. Select **Build PDF Tools APK** and click **Run workflow**. A push to `main`/`master` also starts the workflow automatically.
6. Open the completed workflow run. In **Artifacts**, download **PDF-Tools-APK** and extract `app-debug.apk` from it.

You do not need to create or paste `build.yml` manually; it is already included in this ZIP. If GitHub asks to enable Actions for the repository, enable workflows first.

## Install and test

The artifact is an Android **debug APK**, signed with the standard debug key generated by the Android build. Transfer `app-debug.apk` to your Android phone and install it. Your phone may ask you to allow installation from the file manager/browser used to open the APK. This debug APK is for testing and is **not a Play Store release**.

## Optional local build

Requirements: Node.js 20, Java 17, Android SDK Platform 34 and Build Tools 34.0.0.

```bash
npm install
npm test
npm run build:web
npx cap add android
npx cap sync android
# Apply the supplied icons to android/app/src/main/res/ if desired.
cd android
./gradlew assembleDebug
```

APK output: `android/app/build/outputs/apk/debug/app-debug.apk`.

## Important feature limitations

- **PDF to Word:** extracts selectable text and adds page markers. It does not reproduce the exact visual layout, tables, columns or fonts. Scanned-image PDFs need OCR, which is not included.
- **Word to PDF:** supports `.docx` and `.txt`; it creates a clean text-based PDF. Complex Word formatting, embedded images and tables may not be retained. Older `.doc` files are not supported.
- **Compress PDF:** achieves compression by rasterizing every page into a JPEG image. Searchable text, links, form fields and accessibility structure are not retained. Strong compression can reduce clarity. Always compare the output before using it as an official record.
- **PDF Editor & Sign:** adds a basic text note and/or drawn signature to the bottom of the selected page; it is not a full PDF layout editor and the signature is not a verified digital certificate.
- Encrypted, password-protected, unusually large or damaged PDFs may fail or require substantial phone memory.
- The app is free and does not include advertisements or analytics.
